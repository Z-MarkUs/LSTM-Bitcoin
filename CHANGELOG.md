## [1.0.0] - 2026-09-06

### Added

- A typed, installable `lstm_bitcoin` package and `lstm-bitcoin` command-line interface.
- Chronological, leakage-controlled walk-forward evaluation with naive and linear
  baselines alongside a compact LSTM.
- A pinned data-provenance manifest, input validation, and checksummed reference
  artifacts.
- Transparent forecast metrics and a cost-aware illustrative signal simulation.
- Branch-aware automated tests, linting, strict typing, dependency and static security
  audits, CodeQL, and supported-Python CI.
- Reproducible reference-evaluation and provenance-backed GitHub release workflows.

### Changed

- Reframed the original APS1052 coursework as historical context and replaced its
  unsupported performance claims with verified results and explicit limitations.

### Removed

- Generated IDE state, bytecode, notebook checkpoints, duplicate datasets and notebooks,
  saved model binaries, and temporary presentation files from the maintained branch.
